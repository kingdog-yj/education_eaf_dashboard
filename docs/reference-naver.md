## 1. 배경 · 표면 · 구분선

| 용도 | 값 | 비고 |
|---|---|---|
| 페이지 배경 | `#ffffff` | body |
| 카드/블록 표면 | `rgba(0,0,0,0.01)` ≈ `#fcfcfc` | 흰 배경 위 1% 블랙 틴트 — 거의 흰색인 미세 구분 |
| 보조 표면 | `#eaeaea` | 코드/입력성 요소 |
| 액센트 틴트 표면 | `#0078d4` @ 8% / 15% | 브랜드 블루의 저채도 배경 |
| 구분선(주) | `rgba(0,0,0,0.1)` ≈ `#e6e6e6` | 카드 보더 겸용, 두께 0.667px(2/3px) |
| 구분선(진함) | `rgba(0,0,0,0.19)` ≈ `#cfcfcf` | |
| 구분선(중간) | `rgba(0,0,0,0.12)` | 상단 배너 하단 보더 |

핵심 패턴: 카드는 **그림자 없이** "1% 틴트 표면 + 10% 블랙 서브픽셀 보더"로만 구분.

## 2. 타이포그래피

- **패밀리**: `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Oxygen-Sans, Ubuntu, Cantarell, "Helvetica Neue", sans-serif` (전 요소 동일). 아이콘 전용 `codicon`.
- **본문 기본**: 14px / lh 20~21px / weight 400, 색 `#333333`
- **h1 미사용** (이 페이지 기준)

| 단계 | size / line-height / weight | 용도 (빈도순) |
|---|---|---|
| 11 / 18 / 600 | 라벨·뱃지 |
| 12 / 17 / 500 | 캡션 |
| **14 / 20 / 400·500** | 본문·내비 (최다) |
| 14 / 21~22 / 400 | 본문 변형 |
| 16 / 22.9 / 400 | 리스트·큰 본문 |
| 16 / 22.4~25.6 / 600 | 소제목·강조 |
| 20 / 28.6 / 600 | 버튼·중제목 |
| 24 / 26.4 / 600 | h2, 색 `#1e1e1e` |
| 30 / 39 / 700 | h3(실질 최상위 제목), 색 `#242424` |

텍스트 색 위계: 제목 `#1e1e1e`/`#242424` → 본문 `#333333` → 보조 `#475569`

## 3. 액센트 (hex)

| 용도 | 값 |
|---|---|
| 브랜드/주 버튼 배경 | `#0078d4` (텍스트 `#ffffff`) |
| 링크 강조(하이퍼링크 블루) | `#005fb8` |
| 브랜드 틴트 | `#0078d4` @ a=0.08, 0.15 |
| 일반 링크(카드형 링크) | 텍스트색 계열 `#475569` / `#333333` — 파란 링크는 절제적으로만 사용 |

## 4. border-radius (빈도순)

`2px`(소형 컨트롤, 26회) · `4px`(버튼, 12회) · `10px`(카드, 6회) · `6px`(5회) · `8px`(이미지, 3회) · `12px`(대형 피처 카드) · `3px`

→ 위계: 소형 2~4px, 카드 10px, 히어로급 카드 12px.

## 5. 레이아웃 수치

| 항목 | 값 |
|---|---|
| 본문 최대 폭 | **1280px** (`.body-content`) — 내비는 1441px |
| 본문 컨테이너 padding | `56px 40px 96px` (상/좌우/하) |
| 뉴스 카드 padding | `18px 24px` (카드 폭 395px, 3열) |
| 피처 카드 padding | `16px 20px` (폭 389px) |
| 주 버튼 padding | `8px 16px` |
| 내비게이션 padding | `8px 0` |
| 상단 배너 padding | `0 16px` |
| gap | 기본 **16px** (최다) · 소형 4px/8px · 섹션 간 48px |

## 6. box-shadow

- **카드에는 사용 안 함** (보더+틴트로 대체 — §1 패턴)
- 발견된 2건만:
  - 팝업/오버레이: `rgba(0,0,0,0.2) 0px 10px 30px 0px`
  - 입력 필드 inset: `rgba(0,0,0,0.075) 0px 1px 1px 0px inset`

## 대시보드 적용 시사점 (요약)

- 흰 바탕 + 초저대비 표면(1% 틴트) + 헤어라인 보더(10% 블랙) 조합은 데이터 밀도가 높은 대시보드에서 시각적 소음 없이 블록을 구분하는 데 적합
- 단일 브랜드 블루(1색) + 알파 틴트 2단계만으로 강조 체계 구성 — 액센트 남용 없음
- radius 2단 위계(컨트롤 2~4px / 카드 10px), gap 16px 기본 그리드
